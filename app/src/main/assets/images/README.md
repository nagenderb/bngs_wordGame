# assets/images

Bundled Game 3 images, one folder per language code.

Bundled Game 3 levels reference these through `image.asset` (e.g. `images/te/sample_01.png`) so the game works offline on first launch (Design §5.4, A13).

**The image files referenced by the sample `game3.json` are not included yet** — add real images before running Game 3. Image host, size and count caps are TBD (T12).
